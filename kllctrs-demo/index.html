AI Architecture

Gemini Function Calling

The chatbot has 4 tools registered. Gemini automatically decides which to call based on the user's question. No hardcoded routing — fully dynamic.

search_events — queries Supabase events table
search_shops — queries Supabase shops table
search_sponsors — queries sponsors table
search_ebay_prices — calls eBay Browse API live

Security Model

Layered Protection

Admin access verified at three independent layers. Users can only access their own data. Rate limiting enforced server-side.

proxy.ts middleware — checks profiles.role on every /admin request before rendering
Admin layout — independently verifies app_metadata via supabaseAdmin SDK
API routes — every route validates auth independently, no trust chain
Supabase RLS — row-level security on all tables, enforced at database level
Storage RLS — users can only write to their own avatar folder (user_id/avatar.*)
Rate limiting — 3 free valuations/day tracked in database, checked server-side
